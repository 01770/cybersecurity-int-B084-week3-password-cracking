# 🔐 Week 3: Password Cracking with John the Ripper

My first ever password cracking work! 🎉
I cracked the passwords of 3 locked files: **My Locked PDF 1, My Locked PDF 2, and My Locked PDF 3**.

## 🛠️ Tools I Used
- 🌐 **NetworkWalks**: gave me the hash of each locked file
- 🔓 **John the Ripper (JTR)**: cracked the hash to find the password
- 🖥️ **Johnny (John GUI)**: the Windows version with a simple window

## 💡 What I Learned
Weak passwords can be cracked very fast. Always use long, strong passwords! 💪
